# TRUSTBOX - Anonymous Reporting System

## Team Members
- Hritunjaya Chauhan
- Kashish Sharma
- Jahanvi Deswal

## Project Description
TRUSTBOX is a secure and anonymous reporting system designed for students to report issues such as bullying, harassment, mental health concerns, or any unethical behavior within the campus. The application ensures user privacy through OTP-based login and generates a temporary anonymous ID for each session. Admins can log in with a secure password to view and evaluate all submitted complaints. Complaints that are repeated by multiple users are flagged as "Priority", and repeated submissions by a single ID are marked as "Suspicious".

The interface is clean, responsive, and uses localStorage for complaint storage (demo purpose). A full version would integrate secure backend services with encrypted data handling.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Fonts:** Google Fonts (Poppins)
- **Animations & UI Enhancements:** CSS keyframes, gradients, and transitions
- **Local Storage:** Browser-based `localStorage` for temporary complaint saving
- **OTP Generation (Simulated):** JS-based random 6-digit OTP

## Features
- Anonymous login with college email (only @krmu allowed)
- OTP-based verification (simulated)
- Auto-generated anonymous IDs
- Complaint submission form
- Admin view with complaint analysis
  - Priority: Same complaint reported by multiple users
  - Suspicious: Same complaint reported multiple times by one user
- Ability to clear all complaints (admin only)
- Responsive UI with animations and secure interaction prompts

## How to Run the Project

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, etc.)
- Optional: Code editor like VS Code (for edits or enhancements)

### Steps to Execute
1. **Download or Clone the Repository**
   ```bash

2. **Open the Project**
